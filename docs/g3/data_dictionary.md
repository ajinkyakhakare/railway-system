# G3 Data Dictionary - Reservation & Seat

Database `railway_db`, MySQL 8.0, InnoDB, utf8mb4. Source file: `db/03_schema_g3.sql`.
All `*_ID` primary keys are `INT UNSIGNED AUTO_INCREMENT` (Java type `Long`).

## seat_inventory

Live seat counters for one train run and one class. The counters `Available_CNF`, `RAC_Count` and `WL_Count` are changed only by triggers (`trg_dec_inventory`, `trg_adjust_inventory_on_status`). The row is created by `trg_run_init_inventory` when a `train_run` is inserted. The check `chk_seat_inventory_counters` is the last line of defence against overbooking.

| Field | Type | Null | Key | Default | Description |
|---|---|---|---|---|---|
| Inventory_ID | INT UNSIGNED | NO | PK | AUTO_INCREMENT | Surrogate key of the inventory row. |
| Run_ID | INT UNSIGNED | NO | FK -> train_run(Run_ID); UQ with Class_Code | none | The train run (one train on one date). |
| Class_Code | VARCHAR(3) | NO | FK -> coach_type(Class_Code); UQ with Run_ID | none | Class of travel: SL, 3A, 2A, 1A or CC. |
| Total_Seats | SMALLINT | NO | | none | Number of confirmed seats in this class on this run (coaches x seats per coach). |
| Available_CNF | SMALLINT | NO | | none | Confirmed seats still free. Between 0 and Total_Seats. |
| RAC_Count | SMALLINT | NO | | 0 | Passengers currently in RAC. Between 0 and Max_RAC. |
| WL_Count | SMALLINT | NO | | 0 | Passengers currently on the waiting list. Between 0 and Max_WL. |
| Max_RAC | SMALLINT | NO | | none | Maximum RAC passengers allowed (10% of Total_Seats). |
| Max_WL | SMALLINT | NO | | none | Maximum waiting-list passengers allowed (20% of Total_Seats). |

Constraints: `uq_seat_inventory_run_class` UNIQUE (Run_ID, Class_Code); `fk_seat_inventory_train_run`; `fk_seat_inventory_coach_type`; `chk_seat_inventory_counters` CHECK (Available_CNF BETWEEN 0 AND Total_Seats AND RAC_Count BETWEEN 0 AND Max_RAC AND WL_Count BETWEEN 0 AND Max_WL).

## booking

One PNR: a user books a class on a run for a journey from one station to another.

| Field | Type | Null | Key | Default | Description |
|---|---|---|---|---|---|
| Booking_ID | INT UNSIGNED | NO | PK | AUTO_INCREMENT | Surrogate key of the booking. |
| PNR | CHAR(10) | NO | UQ | none | 10-digit Passenger Name Record number, generated by `fn_generate_pnr`. |
| User_ID | INT UNSIGNED | NO | FK -> app_user(User_ID); IDX | none | User who made the booking. |
| Run_ID | INT UNSIGNED | NO | FK -> train_run(Run_ID); IDX | none | Train run being booked. |
| Class_Code | VARCHAR(3) | NO | | none | Class booked (SL, 3A, 2A, 1A, CC). No foreign key by contract; matched against seat_inventory by the booking procedure. |
| From_Station_ID | INT UNSIGNED | NO | FK -> station(Station_ID) | none | Boarding station. |
| To_Station_ID | INT UNSIGNED | NO | FK -> station(Station_ID) | none | Destination station. Must differ from From_Station_ID. |
| Booking_Status | VARCHAR(16) | NO | | PENDING_PAYMENT | PENDING_PAYMENT, CONFIRMED, CANCELLED or EXPIRED. |
| Total_Fare | DECIMAL(10,2) | NO | | 0 | Sum of Fare_Amount of the passengers, set by `sp_book_ticket`. |
| Booked_At | DATETIME | NO | | CURRENT_TIMESTAMP | When the booking was created; used by `sp_expire_unpaid_bookings`. |

Constraints: `uq_booking_pnr`; `fk_booking_app_user`; `fk_booking_train_run`; `fk_booking_station_from`; `fk_booking_station_to`; `chk_booking_status`; `chk_booking_stations` CHECK (From_Station_ID <> To_Station_ID). Indexes: `idx_booking_user_id`, `idx_booking_run_id`, `idx_booking_status_booked_at` (Booking_Status, Booked_At).

## booking_passenger

One row per passenger travelling on a booking.

| Field | Type | Null | Key | Default | Description |
|---|---|---|---|---|---|
| Booking_Passenger_ID | INT UNSIGNED | NO | PK | AUTO_INCREMENT | Surrogate key; a lower id means an older passenger (used for RAC/WL promotion order). |
| Booking_ID | INT UNSIGNED | NO | FK -> booking(Booking_ID); UQ with Passenger_ID | none | Booking the passenger belongs to. |
| Passenger_ID | INT UNSIGNED | NO | FK -> passenger(Passenger_ID); UQ with Booking_ID; IDX | none | Saved passenger who travels. |
| Status | VARCHAR(10) | NO | | none | CNF, RAC, WL or CANCELLED (see Status lifecycle). |
| Base_Fare | DECIMAL(10,2) | NO | | none | Fare before concession (`fn_base_fare`). |
| Concession_Type | VARCHAR(10) | NO | | none | Effective concession applied at booking time (NONE, SENIOR, CHILD, GOVT, SOLDIER). |
| Fare_Amount | DECIMAL(10,2) | NO | | none | Fare after concession (`fn_net_fare`). |

Constraints: `uq_booking_passenger_booking_passenger` UNIQUE (Booking_ID, Passenger_ID); `fk_booking_passenger_booking`; `fk_booking_passenger_passenger`; `chk_booking_passenger_status`. Indexes: `idx_booking_passenger_passenger_id`, `idx_booking_passenger_status` (Status, Booking_Passenger_ID).

## seat_allocation

The physical seat assigned to a confirmed (CNF) passenger on a run.

| Field | Type | Null | Key | Default | Description |
|---|---|---|---|---|---|
| Allocation_ID | INT UNSIGNED | NO | PK | AUTO_INCREMENT | Surrogate key of the allocation. |
| Run_ID | INT UNSIGNED | NO | FK -> train_run(Run_ID); UQ with Seat_ID | none | Train run the seat is allocated on. |
| Seat_ID | INT UNSIGNED | NO | FK -> seat(Seat_ID); UQ with Run_ID; IDX | none | Physical seat. |
| Booking_Passenger_ID | INT UNSIGNED | NO | FK -> booking_passenger(Booking_Passenger_ID); UQ | none | Passenger who holds the seat (one seat per passenger). |

Index: `idx_seat_allocation_seat_id`.

## booking_status_history

Audit trail of every `booking_passenger.Status` change, written by `trg_adjust_inventory_on_status`.

| Field | Type | Null | Key | Default | Description |
|---|---|---|---|---|---|
| History_ID | INT UNSIGNED | NO | PK | AUTO_INCREMENT | Surrogate key of the history row. |
| Booking_Passenger_ID | INT UNSIGNED | NO | IDX (no FK) | none | Passenger whose status changed. No foreign key by design. |
| Old_Status | VARCHAR(10) | YES | | NULL | Status before the change (NULL when there was none). |
| New_Status | VARCHAR(10) | NO | | none | Status after the change. |
| Changed_At | DATETIME | NO | | CURRENT_TIMESTAMP | Time of the change. |

Index: `idx_booking_status_history_bp` (Booking_Passenger_ID, Changed_At).

## Status lifecycle

### booking_passenger.Status

| Status | Meaning | Set by |
|---|---|---|
| CNF | Confirmed with a seat in `seat_allocation`. | `sp_book_ticket` when Available_CNF > 0; `sp_promote_rac_wl` for RAC -> CNF. |
| RAC | Reservation Against Cancellation: may travel, no full berth yet. | `sp_book_ticket` when no CNF is left and RAC_Count < Max_RAC; `sp_promote_rac_wl` for WL -> RAC. |
| WL | Waiting list. | `sp_book_ticket` when RAC is full and WL_Count < Max_WL. If the waiting list is full, `trg_block_if_wl_full` rejects the insert with BOOKING_CLOSED_WL_FULL. |
| CANCELLED | Cancelled or expired; final state. | `sp_cancel_ticket` (G4) and `sp_expire_unpaid_bookings`. |

Allowed transitions: a new passenger starts as CNF, RAC or WL. Promotion goes WL -> RAC -> CNF in order of Booking_Passenger_ID (oldest first). CNF, RAC or WL can move to CANCELLED. CANCELLED never changes again.

Counter effects (done by triggers, never by procedures): insert CNF decreases Available_CNF by 1; insert RAC increases RAC_Count by 1; insert WL increases WL_Count by 1. Update CNF -> CANCELLED adds 1 to Available_CNF; RAC -> CANCELLED subtracts 1 from RAC_Count; WL -> CANCELLED subtracts 1 from WL_Count; RAC -> CNF subtracts 1 from RAC_Count and 1 from Available_CNF; WL -> RAC subtracts 1 from WL_Count and adds 1 to RAC_Count. Each status change also adds a row to `booking_status_history`.

### booking.Booking_Status

| Status | Meaning | Set by |
|---|---|---|
| PENDING_PAYMENT | Booking created, waiting for payment. Default. | `sp_book_ticket`. |
| CONFIRMED | Payment succeeded. | `trg_payment_confirm` (G4) when a payment becomes SUCCESS. |
| CANCELLED | Every passenger on the booking is cancelled. | `sp_cancel_ticket` (G4). |
| EXPIRED | Payment was not made within the allowed time. | `sp_expire_unpaid_bookings`. |

Allowed transitions: PENDING_PAYMENT -> CONFIRMED (payment), PENDING_PAYMENT -> EXPIRED (timeout), PENDING_PAYMENT -> CANCELLED (all passengers cancelled before payment), CONFIRMED -> CANCELLED (all passengers cancelled). CANCELLED and EXPIRED are final states.
